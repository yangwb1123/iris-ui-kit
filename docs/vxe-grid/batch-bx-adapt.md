## Implementation highlights

- **`pinOf(col)` single throat** — replaces all 4 `col.pinned` read sites (pinnedOffsets, virtual-column union, body attr, flat header attr) + grouped leaf header attr; resolution order: controlled `pinnedColumns` map (a `null` entry overrides static) → internal `pinsInternal` (uncontrolled, `undefined`-checked so explicit `null` unpin wins) → static `col.pinned` seed. `pinnedStyle` inherits by key automatically.
- **Dual channel** (`onColumnWidthsChange` precedent verbatim): `setColumnPinned` fires `onColumnPinnedChange` unconditionally in BOTH modes; uncontrolled flips `pinsInternal` immediately (next render shows the new state), controlled never optimistically flips (parent writes the map back).
- **Menu swap**: the body context menu and the header pin menu are separate `TableContextMenu` instances — `handleHeaderContextMenu` closes the context menu before opening; `handleContextMenu` (body) closes the pin menu first. Exactly one `data-iris-table-context-menu` in the DOM at a time.
- **Right-click zero side effects**: `preventDefault` + `stopPropagation`; sort only fires from the left-button `onClick` path, so a header right-click never sorts / never fires `onHeaderClick` (test-covered).
- **Grouped headers**: group (non-leaf) cells never open the pin menu and never pin; leaf cells get `data-iris-table-pinned` + sticky style (previous flat/grouped asymmetry closed).
- CSS: zero new `var(--iris-*)` usage (pinnedStyle + `var(--iris-surface)` header override already token-driven); zero hardcoded hex.
