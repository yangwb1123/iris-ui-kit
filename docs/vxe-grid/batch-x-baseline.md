**Key findings baked in:**

1. **Vue gap vs React**: Vue `Table.ts` has no proxy controller, no form/toolbar/pager sections, no filter stage (sorts only), and single-column sort only. `loading`/`error` are static props. React has all four surfaces; core already provides the framework-agnostic halves (`createRemoteTableSource` with `sorts` channel + page-reset-to-1, `seedFormValues`/`buildFormValues`/`mergeFormFilters`) — both exported and ready, no core changes needed.
2. **proxyConfig bridge**: new `useTableProxy.ts` composable — controller created in a presence-keyed `watch` (inline-object identity churn safe), `shallowRef` + store subscribe (same pattern as the existing selection/expansion/cellRange bridges), `onScopeDispose` destroy. `tableData` feeds the existing `useTableSort` pipeline; loading/error reuse the already-implemented `error → loading → empty` state rows; pager uses stateless `IrisPagination` (`modelValue`/`total`/`pageSize`), page changes → `setParams({page})` + `onPageChange`.
3. **formConfig**: draft/applied two-state keyed on the field signature (no inline-object wipe), core form materials for submit/reset, proxy path `setParams({filters, page:1})` with the `refetch` fallback on no-op reset; local mode introduces the Vue table's **first filter memo** (`filteredData` before sort) — flagged as genuinely new behavior.
4. **multiSort**: extends `useTableSort.ts` with `cycleMultiSort` (append asc → desc → remove), a standalone pure `buildMultiSortComparator` (chain in click order, first non-zero wins), seq badge `data-iris-sort-seq` on non-primary headers, dual emits (`update:multiSortState` + `multiSortChange` for React-parity listeners), remoteSort pushes the full `sorts` list.
5. **toolbar**: title/refresh/export/buttons/batch only, raw token-styled buttons matching React DOM markers; batch reads the existing `displaySelection`. **Zoom documented as SKIP** (overlay stylesheet + window listeners), plus deferred onImport/columnSettings/seq/layouts.
6. **Tests**: 4 new files next to `Table.test.ts` (~43 cases) using the existing `mount` + `nextTick` harness, mirroring React's `proxy-config`/`form-config`/`multi-sort`/toolbar test shapes; plus pure `buildMultiSortComparator` unit tests. 6 open questions (Vue `filters` prop scope, local filter semantics, grouped-header seq, single-vs-dual emit, pager placement, i18n keys).
