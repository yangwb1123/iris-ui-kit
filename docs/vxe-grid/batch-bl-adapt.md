### Design（per baseline fiats）

- **无回环采样**：渲染顶部 `nowMs()` 打点 + 无依赖 `useLayoutEffect` 提交后推 `{ durationMs, rows, columns, changes }`——push 只通知面板（独立 portal 根 uSES），**表格永不因自身测量重渲**（setState-in-effect 会忙循环）；duration = 渲染 + layout 阶段，排除 paint（文档化）；off = 零成本（门控不推）
- **双订阅**：面板同时订 perf + audit 控制器——`tableRef.clearAuditLog()`（handle 调用不重渲表格）原地刷新变更数；auditLog off → muted `—`
- **无 handle 方法**（spec 未要求，克制 fiat）；core 框架无关、react-only 桥、其余框架零改动
