**关键经验 (Key lessons this cycle):** (1) **source-level cross-framework BEHAVIORAL audits are high-yield** — diffing the interaction surface (keyboard handlers, aria attrs, focus mgmt) of all 4 impls finds real bugs the name-parity guard is blind to (solid-tree-no-keyboard). (2) **The contract harness pays for itself** — the pagination contract caught a real solid bug all per-fw unit tests missed (their aria-current test used CONTROLLED mode; the bug was uncontrolled-only). (3) **Audit a wrapper's COMPOSED primitives, not just its own file** (vue-Select-via-IrisList false alarm). (4) **Solid `<For>` + identity-stable primitive items = stale callbacks** — make per-row reactive state (active/disabled) thunks, never plain values captured at map time.
