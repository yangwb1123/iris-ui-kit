### Design note (deviation from baseline literal text)

The spec's literal 165-char inline `footerSpanMethod` type cannot survive Prettier (~80-char hug threshold for function-typed object members) — so per the hard hygiene rule "inline object params use named exported interfaces", it uses `IrisTableFooterSpanParams`/`IrisTableFooterSpanMethod`; the prop itself stays on one line and the scanner captures the full type (the existing `spanMethod` prop shows what truncation looks like otherwise). Same for `mergeHeaderCells` → `IrisTableMergeCell[]`.
