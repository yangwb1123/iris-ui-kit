**关键经验 (Key lessons this cycle):** (1) **source-level cross-framework BEHAVIORAL audits are high-yield** — diffing the interaction surface (keyboard, aria, focus) of all 4 impls finds real bugs name-parity is blind to. (2) **The contract harness pays for itself** — caught real solid bugs (pagination aria-current; table aria-selected) that per-fw unit tests missed (theirs used CONTROLLED mode / only data-state). (3) **Audit a wrapper's COMPOSED primitives, not just its own file** (vue-Select-via-IrisList false alarm). (4) **Solid `<For>` + identity-stable primitive items = stale callbacks** — per-row reactive state must be thunks, never plain values captured at map time. (5) **ALWAYS read source before concluding a gap** — surface greps gave 3+ false alarms this cycle (vue toast object-literal `role:`; vue Select via IrisList; vue Table aria-selected via different attr). When a grep says "missing," confirm it's not just different syntax/delegation.
