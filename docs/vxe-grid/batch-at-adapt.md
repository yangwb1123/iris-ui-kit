## Deviations / decisions

1. **`AuditLogEntry` 泛型去掉**（`noUnusedLocals` 对未使用类型参数报错——批 D 同款先例，基线未预判）。
2. **commitValue 记同一 `auditDiff`**（而非精确上下文）：两条写入漏斗产出同一形状的条目（行键 + 首变更格），trail 一致性优于精确性；基线建议同款。
3. **`audit-log` 子路径导出**（tsup entry + package.json exports，`./undo` 同款）：文件头 JSDoc 声明独立子路径，不接则名不副实。
4. **类型提示默认 `'edit'`** 覆盖基线 hint map 未列站点（updateRow/查找替换/范围清除/Delete 快捷键/loadData）——全部是"值改写"语义，文档化。
5. **外部数据重喂（父 data / 代理 refetch）不记审计**（非用户变更），但 `auditRowsRef` 经 liveData effect 重基线，下一次用户提交不会对陈旧行做全量 diff。
6. **面板自刷新经 `useSyncExternalStore`** 订阅控制器（version 快照），不依赖父组件重渲染——handle `clearAuditLog` 后面板立即清空。
