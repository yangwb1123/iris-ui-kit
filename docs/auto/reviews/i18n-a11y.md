## i18n / 可访问性审查报告

只读审查完成，未写入文件。按严重度排序：

1. **高｜ColorPicker 指针专用，键盘与 ARIA 缺失**  
   React/Vue/Solid 的色盘、色相、透明度区域是无 `role`/`tabIndex`/键盘处理的 `<div>`：  
   `packages/{react,vue,solid}/src/primitives/color-picker/*`。Svelte 已实现 slider 语义及 `colorPicker.*` 文案。建议统一补充 slider ARIA、键盘调整和本地化值描述。

2. **高｜Image 预览无法由键盘打开，模态焦点未管理**  
   四框架均直接给 `<img>` 绑定 click，无键盘触发；预览虽有 `role="dialog"`，但无 focus trap、初始焦点和关闭后焦点回归。  
   例如：`packages/react/src/primitives/image/Image.tsx:57-86`。

3. **高｜Tour 模态缺少 focus trap 与焦点恢复**  
   四框架的 Tour 仅监听 Escape，`role="dialog" aria-modal="true"` 外没有焦点管理：  
   `packages/{react,vue,solid,svelte}/src/primitives/tour/*`。Tab 可离开模态区域。

4. **高｜Cascader 选项在 React/Vue/Solid 中鼠标专用**  
   选项有 `role="option"` 但无 `tabIndex`/键盘激活；列也缺少 Svelte 已使用的 `cascader.level` 标签。  
   例如：`packages/react/src/primitives/cascader/Cascader.tsx:166-172`。

5. **高｜Resizable/Resizer handles 非交互元素**  
   React/Vue/Solid 使用空 `<div>` 拖拽手柄，无名称、焦点或键盘调整；Svelte 使用按钮并调用 `resizer.handle`。  
   例如：`packages/react/src/behaviors/Resizable.tsx:95-125`。

6. **高｜Splitter 可聚焦但不能键盘调整**  
   React/Vue/Solid 的 separator 有 `tabIndex`，却没有 `keydown` 或可本地化名称；Svelte 已实现方向键和 `splitter.resize`。  
   例如：`packages/react/src/primitives/splitter/Splitter.tsx:112-125`。

7. **中｜Movable/Dragger 的键盘语义跨框架不一致**  
   React/Vue/Solid `IrisMovable` 仅鼠标拖拽；Svelte 才有 button 语义和方向键。`IrisDragger` 四框架均无键盘移动。  
   例如：`packages/solid/src/behaviors/Movable.tsx:101-119`、`packages/svelte/src/behaviors/IrisMovable.svelte:124-131`。

8. **中｜Sortable 仅 Svelte 支持键盘重排**  
   React/Vue/Solid 生成的 sortable item wrapper 不可聚焦、无键盘重排；Svelte 支持 `tabindex` 和方向键。  
   例如：`packages/solid/src/behaviors/IrisSortable.tsx:140-170`。

9. **中｜React/Vue DateRangePicker 的两个空触发器名称相同**  
   React/Vue 仅显示 `dateRangePicker.placeholder`，未使用 `dateRangePicker.start/end`；Solid/Svelte 能区分起止日期。  
   `packages/react/src/primitives/date-range-picker/DateRangePicker.tsx:134`  
   `packages/vue/src/primitives/date-range-picker/DateRangePicker.ts:130`

10. **中｜Transfer 四框架的默认标题、搜索框和复选框语义不一致**
    - React/Vue 不回退到 `transfer.sourceTitle/targetTitle`，未提供 titles 时全选框无名称。
    - Solid 的 item checkbox 未与 label 关联。
    - Solid/Svelte 搜索框只有 placeholder，无 accessible name。  
      例如：`packages/solid/src/primitives/transfer/IrisTransfer.tsx:165-176,284`。

11. **中｜CommandPalette 搜索输入缺少统一可访问关系**  
    Solid/Svelte 搜索 input 缺少 `aria-label={t('commandPalette.search')}`；四框架均未将当前选项通过 `aria-activedescendant` 连接到输入框。  
    例如：`packages/svelte/src/primitives/command-palette/IrisCommandPalette.svelte:173-187`。

12. **中｜FileUpload 隐藏 file input 可能成为无名称 Tab 停靠点**  
    四框架的 visually-hidden `<input type="file">` 没有 `aria-label` 或显式 label；独立使用时与可见 drop zone 分离。  
    例如：`packages/react/src/primitives/file-upload/FileUpload.tsx:219-242`。

13. **中｜Vue FormField 生成了不存在的 hint ID 引用**  
    `packages/vue/src/primitives/form-field/FormField.ts:42-45` 在同时存在 hint/error 时加入 hint ID，但 `:121` 又隐藏 hint，导致 `aria-describedby` 指向不存在元素。

14. **中｜FormField 的 `required` 仅渲染星号**  
    四框架均未向控件注入 `required` 或 `aria-required`；屏幕阅读器无法得知字段必填。  
    例如：`packages/react/src/primitives/form-field/FormField.tsx:90-96`。

15. **低｜CopyButton 的 Copied 状态没有 live announcement**  
    文案从 `copyButton.copy` 变为 `copyButton.copied`，但四框架没有 `aria-live` 状态区，成功反馈依赖焦点名称变化。  
    例如：`packages/react/src/primitives/copy-button/CopyButton.tsx:85-108`。
