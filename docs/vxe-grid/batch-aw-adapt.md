### Design notes

- **Reuse over fork**: the categorical branch reuses the extracted `countDistinctValues` — same exclusion (`null`/`undefined`/`''`), `String` coercion, count-desc + first-appearance tie semantics as the distribution panel, so the top-3 ranking always agrees with the panel's list. `valueDistribution`'s public API is byte-identical (existing tests untouched).
- **One rounding point**: numeric min/max/avg each pass through exactly one `.toFixed(1)`; categorical percentages through one `Math.round`. Percentages are of the non-empty total (a 60%/40% column shows shares of real data, not of the padded row count).
- **Booleans are not numeric**: `Number(true) === 1` would poison a boolean column's range; the branch check excludes them, so a flag column falls to the categorical sentence (`true`/`false` buckets).
- **Panel chain**: five-point clone of the AM distribution chain — reserved key → appended after the distribution item → intercepted at `onSelect` (user callback never sees it) → `openSummary` snapshots the menu's virtual cursor anchor → floating panel with the same dismissal set (Esc / outside pointer-down / any scroll via capture phase).
